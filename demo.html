Overly Detailed

A test page for the userscript. The examples below exercise <details> elements in one arrangement or another.

With the script active, every test section should be open by the time the page settles. Without it, all except the intentionally pre-opened section start closed.

When opening this page as a local file, your userscript manager may need permission to access file:// URLs.

6. Userscript menu commands

These checks use the commands available from your userscript manager's menu.

  • Choose Close all details on this page. Every section should close.
  • Choose Open all details on this page. Every section should reopen.
  • Turn auto-open off and reload. Only the intentionally pre-opened section should begin open.
  • Add a new section while auto-open is off. It should remain closed.
  • Turn auto-open back on. Existing sections should open immediately, and newly added ones should open automatically again.
